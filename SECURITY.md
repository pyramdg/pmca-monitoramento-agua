# Segurança

Não publique vulnerabilidades, senhas, API keys ou dados pessoais em issues.

Para relatar uma falha de segurança, use a opção **Report a vulnerability** na
aba **Security** do repositório. Inclua uma descrição, impacto, forma de
reprodução e, se possível, uma correção sugerida.

Credenciais locais devem ficar somente no arquivo `.env`, que é ignorado pelo
Git. Caso uma credencial seja publicada por engano, revogue-a imediatamente e
gere outra antes de remover o valor do histórico.
